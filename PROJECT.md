# Project Profile

**STARK Hybrid Spatial OS** is an experimental spatial interface controlled primarily through computer vision and hand gestures, with optional mouse interaction.

## What this project demonstrates
- Real-time hand-tracking interaction design
- Gesture-state machines and depth-style click interactions
- Spatial UI concepts with movable information objects
- Performance-aware visual simplification
- Human-computer interaction experimentation in the browser

## Portfolio signal
This repository demonstrates ambitious frontend prototyping at the intersection of computer vision, interaction design and real-time UI systems.

**Domain:** Computer Vision, HCI, Spatial Interfaces  
**Stack:** Web Technologies, Hand Tracking  
**Status:** Active experimental project
